# I. Python

## 1. Python là ngôn ngữ gì?

**Trả lời:**

Python là ngôn ngữ lập trình bậc cao, có cú pháp dễ đọc và hỗ trợ nhiều phong cách lập trình:

* Hướng đối tượng.
* Hướng thủ tục.
* Lập trình hàm.
* Bất đồng bộ.

Python thường được sử dụng cho Backend, AI, Data Science, Automation và scripting.

## 2. List và Tuple khác nhau thế nào?

**Trả lời:**

* `list` có thể thay đổi sau khi tạo.
* `tuple` không thể thay đổi sau khi tạo.

```python
numbers = [1, 2, 3]
numbers.append(4)

coordinates = (10, 20)
```

Tuple thường phù hợp với dữ liệu cố định và có thể dùng làm key trong Dictionary nếu các phần tử bên trong đều hashable.

## 3. Dictionary trong Python là gì?

**Trả lời:**

Dictionary lưu dữ liệu theo dạng key-value:

```python
user = {
    "id": 1,
    "name": "Nghia"
}
```

Thời gian truy cập trung bình theo key là `O(1)`.

Key phải là kiểu hashable như:

* String.
* Number.
* Tuple bất biến.

## 4. `is` và `==` khác nhau thế nào?

**Trả lời:**

* `==` so sánh giá trị.
* `is` kiểm tra hai biến có trỏ đến cùng một object hay không.

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
print(a is b)  # False
```

Với `None`, nên dùng:

```python
if value is None:
    ...
```

## 5. Shallow copy và deep copy khác nhau thế nào?

**Trả lời:**

Shallow copy tạo object mới nhưng các object con vẫn dùng chung tham chiếu.

Deep copy sao chép cả object và các object lồng bên trong.

```python
import copy

shallow = copy.copy(original)
deep = copy.deepcopy(original)
```

## 7. Vì sao không nên dùng List làm giá trị mặc định của tham số?

**Trả lời:**

Ví dụ không nên dùng:

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

List mặc định chỉ được tạo một lần và bị dùng chung giữa các lần gọi.

Nên viết:

```python
def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items
```

## 8. Decorator là gì?

**Trả lời:**

Decorator dùng để bổ sung hành vi cho hàm hoặc class mà không sửa trực tiếp phần cài đặt chính.

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print("Function called")
        return func(*args, **kwargs)

    return wrapper


@log_call
def hello():
    print("Hello")
```

Decorator thường dùng cho:

* Authentication.
* Logging.
* Caching.
* Đo thời gian thực thi.

## 9. Generator là gì?

**Trả lời:**

Generator trả dữ liệu từng phần bằng `yield` thay vì tạo toàn bộ dữ liệu trong bộ nhớ.

```python
def generate_numbers():
    for number in range(1_000_000):
        yield number
```

Generator tiết kiệm bộ nhớ khi xử lý dữ liệu lớn.

## 10. Exception được xử lý như thế nào?

```python
try:

except ZeroDivisionError:

finally:
    print("Hoàn thành")
```

* `try`: Đoạn mã có thể lỗi.
* `except`: Xử lý lỗi.
* `else`: Chạy khi không có lỗi.
* `finally`: Luôn được thực hiện.

```python
with open("data.txt", "r", encoding="utf-8") as file:
```

# II. FastAPI

## 13. FastAPI là gì?

**Trả lời:**

FastAPI là framework Python dùng để xây dựng API.

Đặc điểm:

* Hỗ trợ `async/await`.
* Validation bằng type hint.
* Tự sinh OpenAPI.
* Có giao diện Swagger.
* Hiệu năng tốt.
* Tích hợp Pydantic.

---

## 14. Pydantic dùng để làm gì?

**Trả lời:**

Pydantic dùng để:

* Kiểm tra dữ liệu đầu vào.
* Chuyển đổi kiểu dữ liệu.
* Khai báo schema.
* Serialize response.

```python
from pydantic import BaseModel


class CreateUserRequest(BaseModel):
    name: str
    age: int
```

Nếu Client gửi `age` không hợp lệ, FastAPI tự động trả lỗi validation.

---

## 15. Path Parameter và Query Parameter trong FastAPI?

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}")
def get_user(user_id: int, active: bool = True):
    return {
        "user_id": user_id,
        "active": active,
    }
```

* `user_id` là Path Parameter.
* `active` là Query Parameter.

---

## 16. Dependency Injection trong FastAPI là gì?

**Trả lời:**

FastAPI dùng `Depends` để cung cấp dependency cho endpoint.

```python
from fastapi import Depends


def get_current_user():
    return {"id": 1, "role": "USER"}


@app.get("/profile")
def get_profile(user=Depends(get_current_user)):
    return user
```

Thường dùng cho:

* Authentication.
* Database session.
* Permission.
* Shared validation.

---

## 17. `async def` và `def` trong FastAPI khác nhau thế nào?

**Trả lời:**

Dùng `async def` khi gọi thư viện bất đồng bộ:

```python
@app.get("/users")
async def get_users():
    return await repository.find_all()
```

Dùng `def` với mã đồng bộ.

Không nên gọi hàm I/O blocking lâu bên trong `async def`, vì có thể chặn event loop.

---

## 18. Middleware trong FastAPI là gì?

**Trả lời:**

Middleware chạy trước và sau mỗi request.

```python
@app.middleware("http")
async def add_request_id(request, call_next):
    response = await call_next(request)
    response.headers["X-Request-Id"] = "request-123"
    return response
```

Thường dùng cho:

* Logging.
* CORS.
* Request ID.
* Đo thời gian xử lý.

---

## 19. `response_model` dùng để làm gì?

**Trả lời:**

`response_model` định nghĩa schema dữ liệu trả về.

```python
class UserResponse(BaseModel):
    id: int
    name: str


@app.get("/users/{user_id}", response_model=UserResponse)
def get_user(user_id: int):
    return {
        "id": user_id,
        "name": "Nghia",
        "password": "secret",
    }
```

FastAPI chỉ trả các trường có trong `UserResponse`, giúp tránh lộ dữ liệu nhạy cảm.

---

## 20. BackgroundTasks dùng khi nào?

**Trả lời:**

Dùng cho tác vụ nhẹ cần thực hiện sau khi trả response:

```python
from fastapi import BackgroundTasks


def write_log(message: str):
    print(message)


@app.post("/users")
def create_user(background_tasks: BackgroundTasks):
    background_tasks.add_task(write_log, "User created")
    return {"success": True}
```

Không nên dùng cho tác vụ dài hoặc quan trọng. Khi đó nên dùng Celery, RabbitMQ hoặc hệ thống hàng đợi khác.

---

## 21. FastAPI xử lý lỗi như thế nào?

```python
from fastapi import HTTPException


@app.get("/users/{user_id}")
def get_user(user_id: int):
    if user_id <= 0:
        raise HTTPException(
            status_code=400,
            detail="Invalid user ID",
        )
```

Có thể tạo custom exception handler để chuẩn hóa response lỗi.

## 22. Cách tổ chức dự án FastAPI?

**Trả lời mẫu:**

JavaScript là ngôn ngữ lập trình động, đơn luồng ở mức thực thi mã chính và sử dụng Event Loop để xử lý bất đồng bộ.

## 24. `var`, `let` và `const` khác nhau thế nào?

**Trả lời:**

* `var`: Function scope, có hoisting và có thể khai báo lại.
* `let`: Block scope, có thể gán lại.
* `const`: Block scope, không thể gán lại biến.

```javascript
let count = 1;
count = 2;

const user = { name: "Nghia" };
user.name = "Nam"; // Hợp lệ
```

`const` không làm object trở thành immutable; nó chỉ ngăn gán lại biến.

---

## 25. `==` và `===` khác nhau thế nào?

**Trả lời:**

* `==` có chuyển đổi kiểu trước khi so sánh.
* `===` so sánh cả giá trị và kiểu.

```javascript
"1" == 1;  // true
"1" === 1; // false
```

Thông thường nên ưu tiên `===`.

---

## 26. Hoisting là gì?

**Trả lời:**

Hoisting là hành vi khai báo biến và hàm được xử lý trước khi thực thi mã.

```javascript
console.log(value); // undefined
var value = 10;
```

Với `let` và `const`, biến tồn tại trong Temporal Dead Zone trước dòng khai báo và không thể truy cập.

---

## 27. Closure là gì?

**Trả lời:**

Closure xảy ra khi một hàm vẫn truy cập được biến thuộc phạm vi bên ngoài, ngay cả khi hàm bên ngoài đã kết thúc.

```javascript
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
```

## 28. Promise là gì?

**Trả lời:**

Promise đại diện cho kết quả của một tác vụ bất đồng bộ.

Promise có ba trạng thái:

* Pending.
* Fulfilled.
* Rejected.

```javascript
fetch("/api/users")
  .then((response) => response.json())
  .catch((error) => console.error(error));
```

## 29. `async/await` hoạt động thế nào?

**Trả lời:**

`async/await` là cú pháp giúp xử lý Promise dễ đọc hơn.

```javascript
async function getUsers() {
  try {
    const response = await fetch("/api/users");
    return await response.json();
  } catch (error) {
    console.error(error);
  }
}
```

Hàm `async` luôn trả về Promise.

---

## 30. Event Loop là gì?

**Trả lời:**

Event Loop điều phối:

* Call Stack.
* Task Queue.
* Microtask Queue.
* Web API hoặc Node.js API.

Promise callback thuộc Microtask Queue và thường được xử lý trước callback từ `setTimeout`.

```javascript
console.log("A");

setTimeout(() => console.log("B"), 0);

Promise.resolve().then(() => console.log("C"));

console.log("D");
```

Kết quả:

```text
A
D
C
B
```

## 31. Arrow Function khác Function thường thế nào?

**Trả lời:**

Arrow Function không có `this` riêng mà lấy `this` từ scope bên ngoài.

```javascript
const add = (a, b) => a + b;
```

Không nên dùng Arrow Function làm method khi cần `this` động của object.

## 32. `null` và `undefined` khác nhau thế nào?

* `null`: Giá trị được gán chủ động để biểu thị không có dữ liệu.

```javascript
let a;
```

## 35. `any` và `unknown` khác nhau thế nào?

`unknown` an toàn hơn vì phải kiểm tra kiểu trước khi sử dụng:

## 36. Generic là gì?

```typescript
const result = wrap<number>(10);
```

## 37. Union và Intersection Type là gì?

# V. NestJS

## 41. NestJS là gì?

**Trả lời:**

NestJS là framework Backend cho Node.js, thường dùng TypeScript.

NestJS tổ chức ứng dụng theo module và hỗ trợ:

* Dependency Injection.
* Controller.
* Provider.
* Guard.
* Pipe.
* Interceptor.
* Middleware.

---

## 42. Module trong NestJS là gì?

**Trả lời:**

Module nhóm các thành phần liên quan.

```typescript
@Module({
  controllers: [UsersController],
  providers: [UsersService],
  exports: [UsersService],
})
export class UsersModule {}
```

Một ứng dụng NestJS có ít nhất một Root Module.

---

## 43. Controller dùng để làm gì?

**Trả lời:**

Controller tiếp nhận HTTP request và trả response.

```typescript
@Controller("users")
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get(":id")
  getUser(@Param("id") id: string) {
    return this.usersService.getUser(id);
  }
}
```

Controller không nên chứa quá nhiều Business Logic.

---

## 44. Provider là gì?

**Trả lời:**

Provider là class có thể được NestJS quản lý thông qua Dependency Injection.

```typescript
@Injectable()
export class UsersService {
  getUser(id: string) {
    return { id };
  }
}
```

Service, Repository và Factory đều có thể là Provider.

---

## 45. Dependency Injection trong NestJS hoạt động thế nào?

**Trả lời:**

NestJS tạo và cung cấp dependency cho class thông qua constructor.

```typescript
constructor(
  private readonly usersService: UsersService,
) {}
```

Lợi ích:

* Giảm coupling.
* Dễ mock.
* Dễ unit test.
* Quản lý vòng đời object.

---

## 46. Middleware, Guard, Pipe và Interceptor khác nhau thế nào?

**Trả lời:**

* **Middleware:** Chạy trước Route Handler, thường dùng logging hoặc thay đổi request.
* **Guard:** Quyết định request có được phép tiếp tục không.
* **Pipe:** Validate hoặc chuyển đổi dữ liệu.
* **Interceptor:** Bao quanh quá trình xử lý, dùng logging, transform response, caching.

Luồng đơn giản:

```text
Middleware
→ Guard
→ Interceptor trước
→ Pipe
→ Controller
→ Service
→ Interceptor sau
```

## 53. Overloading và Overriding trong Java?

**Trả lời:**

Overloading: Cùng tên method nhưng khác danh sách tham số.

```java
int sum(int a, int b) { ... }

int sum(int a, int b, int c) { ... }
```

Overriding: Class con ghi đè method của Class cha.

```java
@Override
public void speak() {
    System.out.println("Woof");
}
```

---

## 54. `==` và `equals()` khác nhau thế nào?

**Trả lời:**

Với object:

* `==` so sánh tham chiếu.
* `equals()` so sánh nội dung nếu class đã cài đặt phù hợp.

```java
String a = new String("Hello");
String b = new String("Hello");

System.out.println(a == b);      // false
System.out.println(a.equals(b)); // true
```

---

## 55. Vì sao phải override `hashCode()` khi override `equals()`?

**Trả lời:**

Hai object bằng nhau theo `equals()` phải có cùng `hashCode()`.

Nếu không, các collection như `HashMap` và `HashSet` có thể hoạt động sai.

---

## 56. Checked Exception và Unchecked Exception khác nhau?

**Trả lời:**

Checked Exception được compiler yêu cầu xử lý hoặc khai báo:

```java
IOException
```

Unchecked Exception kế thừa `RuntimeException`:

```java
NullPointerException
IllegalArgumentException
```

Unchecked Exception thường biểu thị lỗi lập trình hoặc dữ liệu không hợp lệ.

---

## 57. Interface và Abstract Class trong Java?

**Trả lời:**

Interface phù hợp để định nghĩa hợp đồng hành vi và hỗ trợ một class triển khai nhiều interface.

Abstract Class phù hợp khi các class có:

* Trạng thái dùng chung.
* Constructor.
* Logic dùng chung.

---

## 58. `final`, `finally` và `finalize` khác nhau?

**Trả lời:**

* `final`: Không cho thay đổi biến, override method hoặc kế thừa class tùy vị trí.
* `finally`: Khối lệnh luôn chạy sau `try/catch`.
* `finalize`: Cơ chế cũ liên quan đến Garbage Collection và không nên dựa vào để giải phóng tài nguyên.

---

## 59. Collection phổ biến trong Java?

**Trả lời:**

* `List`: Có thứ tự, cho phép trùng.
* `Set`: Không chứa phần tử trùng.
* `Map`: Key-value.
* `Queue`: Hàng đợi.

Ví dụ:

```java
List<String> names = new ArrayList<>();
Set<String> emails = new HashSet<>();
Map<Long, User> users = new HashMap<>();
```

---

## 60. ArrayList và LinkedList khác nhau?

**Trả lời:**

`ArrayList`:

* Truy cập theo index nhanh.
* Thường là lựa chọn mặc định.
* Chèn/xóa giữa danh sách có thể tốn chi phí dịch chuyển.

`LinkedList`:

* Truy cập theo index chậm.
* Có thể phù hợp với một số thao tác đầu/cuối.
* Tốn thêm bộ nhớ cho liên kết.

---

## 61. HashMap hoạt động như thế nào?

**Trả lời:**

HashMap dùng `hashCode()` để xác định bucket, sau đó dùng `equals()` để tìm đúng key.

Độ phức tạp trung bình của `get()` và `put()` là `O(1)`.

---

## 62. Thread khác Process thế nào?

**Trả lời:**

Process có không gian bộ nhớ riêng.

Các Thread trong cùng Process chia sẻ bộ nhớ nên giao tiếp nhanh hơn nhưng dễ xảy ra:

* Race condition.
* Deadlock.
* Visibility problem.

## 65. `def` trong Groovy là gì?

Nếu một thành phần là `null`, kết quả trả về `null` thay vì ném `NullPointerException`.
